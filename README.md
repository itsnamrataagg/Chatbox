
# ChatBox - Node.js & MongoDB Chat Application

## Overview
**ChatBox** is a chat application with a **Node.js + Express backend** and a simple **HTML/CSS/JS frontend**. Users can **create, read, update, and delete messages** via APIs. All backend APIs are fully functional in Postman. The frontend allows chatting, though API integration may need proper fetch/axios setup.

## Features
- CRUD operations for chat messages
- RESTful APIs tested in Postman
- Simple frontend chat interface
- MongoDB database integration
- Environment configuration via `.env`

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Frontend:** HTML, CSS, JavaScript
